说明
进销存按流水算：进货加库存，盘点按「实盘」倒推出库并减库存，库存和成本都由流水重算，随时能对上账。
盘点只填数量：不用填卖价 —— 出库按当时的平均成本结转，所以「已实现利润」不单独算，利润就是总资产的增量（总资产 = 手上现金 + 库存占用）。
摆摊不用一件件记：数完剩多少件，把「实盘」填上，右邻的「出库」立刻算出 =（库存 − 实盘）；点「确认盘点」一次性把这批出库按「卖价」入账。卖价留空会沿用该类上次卖价。
盘盈（实盘比账面多）会自动按当前平均成本补回库存，不产生利润，流水里标「盈」。
总资产 = 手上现金 + 库存占用（库存按进货成本计，不按卖价浮估）。现金填在盘点栏，每次点「确认盘点」会把当时的现金、库存占用、总资产记成一条「盘点记录」，并标出较上次多了多少 —— 这就是这轮倒卖赚的钱。
成本用移动加权平均：进货后平均成本 = 库存总成本 ÷ 库存件数；出库按当时平均成本结转。
没进过货的品类，盘盈会按 0 成本入库（库存金额不涨）—— 想让货有价，先按进价记一笔进货。
「库存流水」里点 ✕ 可撤销任意一笔（含盘点写进去的那些），但会让后面某次出库超出库存的那笔不允许删。
「进货价走势」按品类看每次进货价：折线是各笔进价，下面给笔数 / 件数 / 最高 / 最低 / 加权均价。
这块和「收益测算」的挂机收益完全独立（不在同一页，也不进那边的 KPI）。
